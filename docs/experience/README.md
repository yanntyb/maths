# Expériences — déploiement de concepts

> [Retour à l'index](../README.md)

Les **expériences** sont des explorations structurées de concepts mathématiques. Chacune prend une intuition comprimée et la **déploie rigoureusement** en étapes interprétables, testables et reproductibles.

## Sens

Une expérience révèle comment une **phrase dense** cache plusieurs mouvements mathématiques distincts. Elle les sépare, les formalise, les enchaîne.

## Contrat

```
phrase comprimée (intuition)  →  5 mouvements déployés  →  formulation rigoureuse
```

Chaque expérience livre :
- La phrase source (l'intuition)
- La décompression en mouvements élémentaires
- La formalisation avec définitions précises
- Les obstacles théoriques (barrières, verrous, manques de preuve)
- Un exemple concret d'application

## Expériences

### 1. Décompression de phrase — solidité via zêta arithmétique

> La phrase : *« Modifier les axiomes d'un système formel modifie la densité de ses formules-entiers via Gödel, ce qui modifie l'abscisse de convergence de sa zêta arithmétique ; cette variation Δσ_c mesure rigoureusement combien chaque axiome contribue à la richesse arithmétique du système. »*

**Sens** — comment une intuition sur l'essentialité arithmétique peut devenir un diagnostic mathématique

**Contrat** — prendre une phrase philosophique, l'étager en cinq mouvements, en exposer la rigueur et les manques

**Cablages** — l'encodage de Gödel, la zêta de Riemann, l'abscisse de convergence, le test différentiel de perturbation
