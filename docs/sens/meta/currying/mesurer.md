# Currying — Mesurer

> [Retour au sens](../../mesurer/)

Fixer `phi` dans [observer](../../observer/) produit une **forme lineaire** `E -> R` : un instrument de mesure qui lit tout vecteur selon une direction fixee.

```
curry(observer)(phi) = phi(_) : E -> R
```
