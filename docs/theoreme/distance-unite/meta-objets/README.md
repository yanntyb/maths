# Meta-objets — distance unite

> [Retour a Distance unite](../README.md) | [Sens locaux](../sens/) | [Meta-objets globaux](../../../meta-objets/README.md)

Un meta-objet ne transforme pas des **valeurs**. Il transforme des **structures** : ici, des sous-groupes en corps et inversement.

## Catalogue

| Meta-objet | Contrat | Role dans la preuve |
|------------|---------|---------------------|
| [Galois](galois.md) | `Sous-groupes fermes(G) <-> Corps intermediaires` | lire cote corps la tour construite cote groupe |

## Distinction avec les sens locaux

| | Sens local (ex. [Plonger](../sens/plonger/)) | Meta-objet (Galois) |
|---|---|---|
| **Entree** | un element `x ∈ K` | un sous-groupe `H ⊂ G` |
| **Sortie** | une valeur (`V`, `Q`, `R_+`) | un corps |
| **Question** | « que vaut x ? » | « quel corps correspond a ce groupe ? » |
